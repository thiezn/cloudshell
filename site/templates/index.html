AWS CloudShell, from your terminal.

Create and manage AWS CloudShell environments, inspect VPCs, and connect to an interactive shell with a small Rust library and CLI.

Get started → View source

What it does

A direct path to your shell.

01

Environment lifecycle

List, create, start, stop, inspect, and delete CloudShell environments without leaving your terminal.

02

Interactive connection

Wait for readiness, start suspended environments, and open a shell through the Rust Session Manager bridge.

03

VPC discovery

Inspect VPCs, subnets, availability zones, and security groups before creating a networked environment.

Quick start

Create an environment, then connect.

Use your configured AWS credentials to create a public environment and open an interactive shell.

Explore the CLI reference → 
$ environment_id=$(cloudshell create)
$ cloudshell connect "$environment_id"
